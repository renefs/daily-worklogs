# About this application

- Goal: Create a desktop application for Windows, Linux, and macOS that allows users to store, edit, and visualize their daily worklog using markdown files.

- Requirements:
    - It lets the user store the mardown files where he chooses in the file system. It must allow export the files or use them in another applications.
    - The application must include a markdown editor
    - Must include a visualizer of the files.
    - Must have a button to create daily notes for the worklog.
    - Must include a view to visualize the notes of the last week (mon-sun but also allow the user to customize the start/end of the week).
    - The application should use a modern and friendly design and must include different color schemes.
    - The application must be fast and responsive.
    - It must be easy to use and understand.
    - It must be able to run in Windows, Linux, and macOS.
    - It must be able to run in spanish and english, and the user must be able to switch between them. In the future, it should support other languages. Default language must be english.
    - All the code must be in english.
    - The application must use a modular architecture and must be easy to extend.
    - Use modern design principles and a friendly and modern UI.
    - The application must follow the principle of design not AI-assisted.
    - For UI components Mantine UI. Also for the design.
    - It must provide a calendar to select the notes of any day, week (content of the notes from the week, not editable) and month (content of the notes of the day of the selected month, not editable.)

- Choose the best suitable technology to acomplish the goal
